# EagleCad Libraries

This folder contains the legacy Eagle libraries kept for reference and compatibility.

## Contents

- Resistor libraries for 0402, 0603, 0805, and 1206
- Capacitor libraries for 0603

## Notes

- These files are the older Eagle workflow and are not the preferred path for new work.
- The KiCad libraries live in [Libraries/Kicad](Libraries/Kicad).
